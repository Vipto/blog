# Vipto — Official Technology & Product Journal

> **“Building technology that makes everyday product discovery simpler.”**
>
> **“Search Online. Confirm Availability. Buy Offline.”**

Vipto is an **unincorporated technology product initiative** exploring how technology can solve the practical friction between searching online and finding verified products in nearby local physical stores.

This repository contains the source code for the official digital publication, research notes, and product journal of Vipto, built with **Next.js (App Router)**, **TypeScript**, and a clean **Vanilla CSS Design System**.

---

## 🧭 Core Purpose & Vision

Every day, people need items immediately from physical stores in their neighborhood (e.g. urgent replacement chargers, specific medications, books, stationary). However, existing platforms either focus on warehouse e-commerce with multi-day shipping (Amazon/Flipkart) or map pins that show storefronts without revealing shelf inventory (Google Maps/Justdial).

Vipto bridges this gap through a lightweight, request-based workflow:
1. **Search Online**: Discover products across nearby stores sorted by real-world walking/driving distance.
2. **Confirm Availability**: Send a one-tap availability request directly to the store owner's mobile screen.
3. **One-Tap Reply**: The store owner taps either **"Available"** or **"Not Available"** in under 2 seconds.
4. **Buy Offline**: The customer navigates directly to the store with complete certainty.

---

## 🏗️ Architecture & Dual-App Model

Vipto consists of two decoupled applications:

- **Customer App**: Clean product discovery, location-aware category browsing, one-tap stock inquiries, live request status tracking, and turn-by-turn store navigation.
- **Seller App**: Frictionless store registration, rapid camera-based item cataloging (no complex ERP or barcode scanning needed), high-contrast two-tap request inbox, and instant local visibility.

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Vipto/vipto-blog.git

# Navigate into the project directory
cd vipto-blog

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
